# Project 02 – Amazon CloudFront CDN with Secure S3 Integration

## Objective

Deliver a static website securely using Amazon CloudFront and Amazon S3.

## AWS Services

* Amazon CloudFront
* Amazon S3
* Origin Access Control (OAC)

## Skills Demonstrated

* CloudFront distribution creation
* Secure S3 origin configuration
* Origin Access Control (OAC)
* Bucket policy configuration
* Cache invalidation
* Default root object configuration
* Access troubleshooting

## Outcome

Successfully deployed a secure CloudFront CDN integrated with Amazon S3 and resolved access issues to deliver content globally.
