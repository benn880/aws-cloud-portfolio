# ☁️ Project 05 – Secure EC2 Web Server

## 📖 Overview

This project demonstrates the deployment of a secure Linux web server on Amazon EC2. The environment was configured using AWS Identity and Access Management (IAM), AWS Systems Manager Session Manager for secure administration, Security Groups for network access control, and Apache HTTP Server for hosting a custom HTML/CSS portfolio website.

---

## 🎯 Project Objectives

- Launch an Amazon EC2 instance
- Configure secure access using AWS Systems Manager
- Create and attach an IAM role
- Configure Security Groups
- Install and configure Apache HTTP Server
- Deploy a custom HTML/CSS portfolio website
- Verify public web access
- Troubleshoot connectivity and networking issues
